\begin{abstract}
Meta-Diffusion adapts a frozen denoising diffusion probabilistic model to a new data domain
by fitting a low-dimensional task coordinate rather than by updating network weights. This
report gives the results of the current experimental stage, block by block against the
governing plan. The plan fixes the criterion in advance: the main claim holds only if the
correct source task together with a learned source-to-target relation outperforms
\emph{both} relation-only transfer \emph{and} target-only few-shot modelling. That criterion
is met when target data are scarce, and only then. Six of the ten deliverables are complete;
four are not, and each is named with its reason.
\end{abstract}

\section{Criterion and notation}

\paragraph{Criterion.} The main claim is supported only if the correct source task
\emph{plus} the learned source-to-target relation outperforms \emph{both} relation-only
transfer \emph{and} target-only few-shot modelling, in the low-target-data regime.

\paragraph{Notation.} A set encoder maps a set of images to a task coordinate
$z \in \mathbb{R}^{k}$. Writing $z_S$ for the coordinate encoded from source-domain data and
$c$ for a descriptor of the source-to-target relation, the transport map predicts the target
coordinate $\tilde{z}_T = z_S + \Delta_\gamma(z_S, c)$, taking no target image as input.
$M_S$ is the number of source images the encoder sees; $K_T$ is the number of target images
available at adaptation time. Feature-wise linear modulation, the standard alternative to an
additive basis, scales and shifts intermediate feature maps as a function of the coordinate;
it is called the modulation arm below.

\paragraph{Metric.} Distances are the sliced Wasserstein distance to the real target set in
pixel space, which the plan names as headline; lower is better. Every comparison is a paired
difference over episodes with a 95\% confidence interval, and an asterisk marks an interval
excluding zero.

\paragraph{Configuration.} One checkpoint of the three-transformation CIFAR-100 domain-shift
family --- Gaussian blur, additive Gaussian noise, contrast reduction at severity 3 --- a
U-Net backbone of 128 base channels, coordinate dimension $k=16$, 50{,}000 training steps
read with exponentially moving averaged weights. Adaptation uses 25 refinement steps at rate
$10^{-2}$. Generation uses the deterministic implicit sampler, 50 reverse steps, 96 samples
per cell, 60 episodes per cell.

\paragraph{Conclusion.} The method beats all three source controls at every budget. It beats
relation-only transfer and target-only modelling simultaneously at one and five target
images, which is what the criterion requires, and the advantage over target-only modelling is
gone by twenty. \textbf{The criterion is met in the low-target-data regime and is bounded
there:} source information is worth having when target evidence is scarce, and its value
decays as target evidence accumulates. A gap to the oracle remains at every budget.

there is no crossing, only a convergence} --- the two become indistinguishable from two
target images onward, and the method was never shown to fall behind.

\subsection{A4 --- Source-abundance sweep}

Six source budgets from 16 to 300 images, one target image, 60 episodes each.

\begin{figure}[h]
\centering
\includegraphics[width=\textwidth]{A4_ms_curve.png}
\caption{A4. Left: absolute distance per strategy. Right: paired differences with 95\%
intervals.}
\end{figure}

\paragraph{Conclusion.} Across a nineteenfold range nothing moves: the comparison against
reusing the source coordinate shifts by $0.0002$, that against target-only modelling by
$0.0019$, that against the oracle by $0.0011$, each smaller than the half-width of its own
interval. The plan expected improvement followed by saturation. \textbf{What the sweep shows
is saturation from the first point measured: sixteen source images already buy everything
this transport map extracts from a source set.} The method is therefore cheap on the source
side. The sweep varies source evidence available at deployment; the checkpoint was trained
once, at $M_S = 64$.

\section{Stage D --- Few-shot face generation}

\textbf{No new runs, as the plan directs.} The existing negative result stands, reinterpreted
as a task-family mismatch: the standard setup offers a handful of heterogeneous target
domains rather than many instances of one reusable relation. A1 supports that reading, since
the method's advantage is concentrated where a reusable relation carries information a single
target image does not.

\section{Conclusion}

The criterion fixed before the stage began is met, and met narrowly: the correct source task
together with the learned relation beats both relation-only transfer and target-only
modelling when target data are scarce, with the margin over target-only modelling gone by
twenty target images. The positive control confirms the mechanism is sound where the ground
truth is known and locates the difficulty on images as shallowness rather than absence. Two
further results are usefully negative: source evidence saturates below the smallest budget
measured, so the method is cheap on the source side, and the non-linear transport map is not
distinguishable from a linear one, so the architecture can be simplified.

Three items would change what can be claimed. The unconstrained fine-tuning reference, which
is implemented but was not run, would establish whether the remaining gap to the oracle
belongs to the task or to the architecture. The branch integration of 0.1 unblocks
deliverable~3 and is a repository operation. And the image release behind C0 is the only
route to a task family in which a single target example does not already reveal the task ---
which, on the evidence of A1, is where this method has the most to offer.
