\begin{abstract}
We report the results of the current experimental stage for Meta-Diffusion, a method that
adapts a frozen denoising diffusion probabilistic model to a new data domain by fitting a
low-dimensional task coordinate rather than by updating network weights. The report is
organised block by block against the governing experimental plan, so that every item the
plan specifies appears here with either its result or the reason it was not run. The plan
fixes the criterion for the main claim in advance: the claim is supported only if knowledge
of the correct source task, combined with a learned source-to-target relation, outperforms
\emph{both} transfer that knows only the relation \emph{and} few-shot modelling that uses
only target-domain data. On the distributional metric the plan names as headline, that
criterion is met in the low-target-data regime and only there. With a single target image
the method improves on relation-only transfer by $+0.025 \pm 0.008$ and on target-only
modelling by $+0.018 \pm 0.009$; the advantage over target-only modelling has vanished by
twenty target images. Of the ten deliverables the plan fixes, six are complete and four are
deferred. Two earlier readings are withdrawn, both traceable to a measurement instrument
blind to the quantity under test.
\end{abstract}

\section{Scope, criterion and notation}

This report follows the plan's own structure and numbering. Sections~\ref{sec:stage0}
through \ref{sec:staged} correspond one to one with the plan's Stage 0 through Stage D;
Section~\ref{sec:cross} reports against its cross-cutting requirements and
Section~\ref{sec:deliverables} against its list of final deliverables. Each block states
what the plan asked, then either what was run and what it returned, or why it was not run.

\paragraph{The criterion.} The plan states the criterion for the main claim without
qualification: the claim is supported only if the correct source task \emph{plus} the
learned source-to-target relation outperforms \emph{both} relation-only transfer \emph{and}
target-only few-shot modelling, in the low-target-data regime. Any other outcome is to be
reported as what it is.

\paragraph{The model.} The backbone is a denoising diffusion probabilistic model: a network
trained to predict the noise added to an image at a randomly chosen point along a fixed
corruption schedule, so that running the schedule backwards generates samples. Generation
uses the denoising diffusion implicit model sampler with the stochasticity parameter set to
zero, which makes sampling deterministic given the initial noise.

\paragraph{The coordinate and the transport map.} A set encoder $r_\psi$ maps a set of
images to a task coordinate $z \in \mathbb{R}^{k}$. Writing $z_S$ for the coordinate encoded
from source-domain data and $c$ for a descriptor of the source-to-target relation, the
transport map produces the predicted target coordinate
$\tilde{z}_T = z_S + \Delta_\gamma(z_S, c)$. The map takes no target image as input; target
images enter only through an optional refinement step that minimises the denoising loss over
the coordinate alone, with the network frozen.

\paragraph{Notation, as the plan defines it.} $M_S$ is the number of source-domain images
the encoder sees when producing $z_S$. $K_T$ is the number of target-domain images available
at adaptation time. Feature-wise linear modulation, abbreviated below as the modulation arm,
is the standard alternative to an additive basis: it scales and shifts intermediate feature
maps as a function of the coordinate instead of adding a learned direction to the score.

\paragraph{Two instruments.} The first is a transformation statistic: three fixed
convolutions measuring mean absolute Laplacian response, per-image standard deviation and
residual above a local average. It reads which image transformation was applied and nothing
else. The second is the sliced Wasserstein distance in pixel space, which compares two sets
of images by projecting both onto many random directions, sorting each projection and
comparing quantiles. The plan names the second as the headline distributional metric.
Section~\ref{sec:a1} shows that the choice between them is not cosmetic.

\paragraph{Statistics.} Every comparison is a paired difference computed episode by episode
and reported with a 95\% confidence interval; an interval excluding zero is marked with an
asterisk. An interval containing zero means the sign is not determined at this sample size.
It does not establish equality, which would require a separately declared margin of
indifference that none of these comparisons carries.

\paragraph{A departure from the written configuration, now corrected.} The configuration
file recorded 32 noise draws per refinement step only after this stage began. The field
previously read 16 and was never passed to the object that consumes it, so every number
produced before the correction was in fact generated with that object's own default of 32.

moved when it was, and both are identified where they occur.

\subsection{A1 --- Source-dependence controls}
\label{sec:a1}

\planasked Four conditions on the three-transformation setup --- the correct source
coordinate, a within-relation shuffled source, the mean source coordinate and relation-only
--- with the distributional metric as headline and paired intervals throughout. The plan
adds an instruction: if relation-only matches the full method, say so explicitly and narrow
the source-informed claim, because that outcome is reportable rather than a failure.

\whatran 180 episodes, twenty classes by three transformations by
$K_T \in \{1,5,20\}$, nine conditions, 96 samples per cell.

\result The method beats all three source controls on the headline metric, in all nine
cells, every interval clear of zero (Table~\ref{tab:a1}). The outcome the plan warned about
did not occur: relation-only is comfortably beaten.

\paragraph{The criterion is met, with a boundary.} At a single target image the method beats
relation-only transfer and target-only modelling simultaneously, which is what the plan
requires. The advantage over target-only modelling survives to five target images and is
gone by twenty. The claim is therefore explicitly bounded: source information is worth
having when target evidence is scarce, and its value decays as target evidence accumulates.
That boundary is consistent with the task family, in which a single target image already
reveals which transformation was applied.

\paragraph{The two instruments disagree, and the disagreement is the finding.} Under the
transformation statistic the comparison against the mean source coordinate contains zero at
every budget. That instrument reads which transformation was applied; the within-relation
mean preserves the transformation exactly and destroys only task identity. The instrument is
blind by construction to precisely the quantity the control removes, so a null reading from
it carries no information about that quantity. An earlier reading of this panel concluded
that the task-specific content of the coordinate went unused. That conclusion was drawn from
the blind instrument and is withdrawn.

\paragraph{The gap to the oracle is real.} The method remains behind the oracle by $+0.026$,
$+0.027$ and $+0.017$ at the three budgets, every interval excluding zero. Earlier
statements that the method was indistinguishable from the oracle came from the loss-shaped
instrument and are likewise withdrawn.

\subsection{A3 --- Target-scarcity sweep}

\planasked Sweep $K_T$ and name the crossing point at which target-only modelling catches
up.

\whatran 300 episodes at $K_T \in \{1,2,5,10,20\}$.

\result The method beats reusing the source coordinate at every budget, the advantage
decaying monotonically from $+1.140 \pm 0.108$ to $+0.229 \pm 0.059$ with every interval
clear of zero. This is the largest and most robust effect in the stage, an order of magnitude
above every other comparison.

\paragraph{The crossing point, as the plan asks it to be named.} There is no crossing. The
correct statement is a convergence: the advantage over target-only modelling is confined to
the smallest budgets and the two become indistinguishable thereafter. An earlier run had read
the twenty-image budget as the method \emph{losing}, $-0.017 \pm 0.044$, and that was written
up as a crossing. The larger run reads $+0.008 \pm 0.036$: the sign reversed and both
intervals contain zero, so the method was never shown to lose. That write-up is retracted.

\subsection{A4 --- Source-abundance sweep}

\planasked Fix one target image and sweep the source budget over
$\{16, 32, 64, 128, 256, 300\}$, using the nested subsampling of 0.4 so that set identity is
not confounded with set size. The plan states its expected shape: improvement with increasing
source evidence, then saturation.

\whatran All six budgets, 60 episodes each, one checkpoint throughout.

\result Saturation from the first point measured, with no improvement phase at all
(Figure~\ref{fig:a4}). Across a nineteenfold range the comparison against reusing the source
coordinate moves 0.0002, that against target-only modelling 0.0019 and that against the
oracle 0.0011 --- each smaller than the half-width of its own interval at either end.
Sixteen source images already buy everything this transport map extracts from a source set.
Reported as what it is, per the plan's instruction.

\paragraph{The sweep's internal check.} Two strategies in the panel never consult the source

trained transport map requires at deployment. It does not measure how that map would differ
had it been trained under a different source budget; see Section~\ref{sec:excluded}.

\paragraph{The floor, and what it permits us to claim.} These are four separately trained

\section{Stage B --- Gaussian-mixture positive control}
\label{sec:stageb}

\planasked A cheap positive control on two-dimensional Gaussian mixtures, where the ground
truth is analytic, together with a sweep of the distance between source and target tasks.

\whatran Five task families spanning that distance, 32 tasks each.

\result The mechanism behaves as designed. The paired improvement from using a task's own
coordinate rather than the coordinate shared by all tasks runs from $+0.1428$ to $+0.1571$
across the five families, every interval excluding zero, and the task-specific share of the
gain is $1.0$: on analytic mixtures essentially the whole benefit of the coordinate is
specific to the task rather than a constant offset. The coordinate-loss profile is minimised
at the task's own coordinate in all five families, which is the correctness check the panel
exists to perform.

Figure~\ref{fig:profile} places this beside the corresponding measurement on images. The two
loss scales are not comparable, so the figure plots the depth of the well as a percentage of
the loss at the shared mean coordinate, which is. The well is 26.1\% deep on mixtures and
1.6\% deep on CIFAR-100, and both are minimised in the right place with the wrong direction
rising monotonically. The mechanism on images is therefore neither absent nor misdirected. It
is shallow, and an earlier reading that described it as flat was overstating.

\begin{figure}[t]
\centering
\includegraphics[width=\textwidth]{profile_contrast.png}
\caption{The coordinate-loss profile on two-dimensional Gaussian mixtures (left) and on
CIFAR-100 domain shift (right). The horizontal axis walks the coordinate from the shared mean
at $s=0$ through the task's own coordinate at $s=1$ and out to twice that displacement. Both
are minimised at $s=1$; the depth of the well differs by roughly sixteenfold.}
\label{fig:profile}
\end{figure}

\paragraph{What the sweep did not produce.} The relatedness sweep was built to vary the
distance between source and target tasks, and it does not move the task-specific term: the
five readings are $+0.1539$, $+0.1428$, $+0.1536$, $+0.1571$ and $+0.1533$, from the smallest
perturbation through to unrelated task pairs. The dial turns; the quantity it was built to
move does not. We record this as an open question rather than a footnote.

\label{sec:staged}

\planasked No new runs. The existing negative result stands and is retained, reinterpreted
as a task-family mismatch rather than as evidence against the mechanism, with only the

\result Complied with by construction: no runs were performed. We record the

\section{Cross-cutting requirements}
\label{sec:cross}

\subsection{Baselines}

The plan fixes a minimum baseline set for any headline comparison. Present and reported
here: target-only conditioning, direct source reuse, relation-only prediction, additive basis
with transport, and transport with and without refinement. Absent: the modulation arm with
matched transport, for the reasons in A2; low-rank or adapter adaptation, which the plan
itself notes does not exist and would be new work to be scheduled only after Stage A;
and full or partial fine-tuning, which is implemented and reachable but was not run.

\paragraph{On the fine-tuning reference.} The plan cautions against using equal optimisation
steps as the only fairness criterion for it. We add that it is the measurement that would
attribute the oracle gap of Section~\ref{sec:a1} either to the task or to the basis and
backbone, and identify it as the cheapest informative next step.

\subsection{Evaluation discipline}

Every condition is paired on the same episodes, target-query samples and generation seeds,
and this was strengthened mid-stage when refinement noise was brought under a per-episode
stream. All differences are reported as absolute paired differences with 95\% intervals. No
ratio with a vanishing denominator is headlined anywhere in this report; where such a ratio
appears in a source file it is accompanied by the absolute difference, which is the quantity
we quote. No raw loss curve is presented as evidence about task specificity.

\paragraph{Refinement, and the plan's rule about it.} The plan directs that refinement not be
promoted into the headline method unless it shows a reliable generation benefit. It does not.
The two instruments disagree on its sign, and four measurements of the one-image cell span
0.023 while their half-widths are approximately 0.014. It stays out. Its value is real when
the starting coordinate is far away --- reusing the source coordinate improves from 1.439 to
0.521 across the target-budget range through refinement alone --- and unmeasurable once
transport has landed close.

\subsection{Excluded work}
\label{sec:excluded}

\paragraph{The dSprites intermediate stage.} Excluded by the plan, its role reassigned to the
demographic experiment. Section~\ref{sec:a1} gives that decision more weight than it had when
taken: the advantage over target-only modelling disappears by twenty target images precisely
because a single target image already reveals the task, which is the condition dSprites was
designed to remove. With Stage C blocked at C0, no experiment in this stage supplies that
condition.

\paragraph{The severity sweep.} Excluded unless required to interpret a Stage A result. It
was not required. The flag remains wired and verified.

\paragraph{A sweep of the training-time source budget.} We considered whether the flat A4
curve reflects what the transport map learned under a fixed training budget rather than a
property of the task. Testing that would require retraining at several source budgets. The
plan contains no such experiment --- every mention of the source budget in it refers to the
evaluation script, and its overall posture is that the implementation is frozen. It is
recorded here as an open question and was not run.

\section{Limitations}
\label{sec:limits}

Four limitations travel with every number here.

First, all CIFAR-100 results come from a single checkpoint and a single seed. Every interval
is a within-run interval over episodes and contains no seed-to-seed component. This matters
most in A5, where four separately trained models are compared and run-to-run variation is the
dominant nuisance term; the floor reported there is estimated from four runs, not bounded.

Second, all readings are on the validation split. The test split is untouched and reserved
for a single final number, as the plan requires.

Third, absolute generative quality is unmeasured. The kernel Inception distance of 0.4 was
not implemented, and no real-against-real control establishes the floor of the sliced
Wasserstein distance at these sample sizes. The oracle row functions as a practical floor,
but no absolute distance reported here should be read as a distance from zero. What this
report establishes is that the coordinate controls generation, not that the generated images
are good.

Fourth, the two instruments disagree in at least one place where the disagreement changes a
conclusion, and the resolution in Section~\ref{sec:a1} rests on an argument about what each
instrument can see rather than on a third measurement.

\section{Conclusion}

The criterion fixed before the stage began is met, and met narrowly: knowing the source task
and the relation beats both relation-only transfer and target-only modelling when target data
are scarce, and the margin over target-only modelling is gone by twenty target images. The
positive control confirms the mechanism is sound where the ground truth is known and locates
the difficulty on images precisely: the well is shallow, not absent. Two supporting results
are negative in a useful way --- source evidence saturates below the smallest budget measured,
so the method is cheap on the source side, and the non-linear transport map is not
distinguishable from a linear one, so the architecture can be simplified rather than defended.

Three items would change what can be claimed. The unconstrained fine-tuning reference would
establish whether the remaining gap to the oracle belongs to the task or to the architecture.
The branch integration of 0.1, a repository operation rather than an experiment, unblocks
deliverable~3. And the image release behind C0 is the only route to a task family in which a
single target example does not already reveal the task --- which, on the evidence of A1, is
the condition under which this method has the most to offer.
